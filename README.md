# Ona releases

Downloads for Ona, the desktop coding agent from Vorynza. Installed copies update themselves from the releases here.

Latest version, always current:

- Linux AppImage: [ona-x86_64.AppImage](https://github.com/codewic/ona-releases/releases/latest/download/ona-x86_64.AppImage)
- Debian and Ubuntu: [ona-amd64.deb](https://github.com/codewic/ona-releases/releases/latest/download/ona-amd64.deb)
- VS Code extension: [ona-vscode.vsix](https://github.com/codewic/ona-releases/releases/latest/download/ona-vscode.vsix) (install with `code --install-extension ona-vscode.vsix`)

Windows and macOS builds are coming.
